Polimorfismo dinámico en Python

Descubre cómo diferentes objetos pueden responder de distintas maneras ante una misma operación. Aprende sus mecanismos, aplicaciones y buenas prácticas mediante ejemplos prácticos.

Comenzar aprendizaje
ejemplo.py
class Animal:
    def sonido(self):
        print("Sonido general")

class Perro(Animal):
    def sonido(self):
        print("Guau")

class Gato(Animal):
    def sonido(self):
        print("Miau")

animales = [Perro(), Gato()]

for animal in animales:
    animal.sonido()
Salida: Guau / Miau
01 / FUNDAMENTOS

Fundamentos e Introducción

El polimorfismo es uno de los principios fundamentales de la programación orientada a objetos. Permite que diferentes objetos respondan de distintas maneras ante una misma operación.

01

¿Qué significa?

La palabra polimorfismo significa muchas formas. En programación, permite utilizar una misma operación con diferentes objetos, obteniendo comportamientos distintos.

02

¿Para qué sirve?

Facilita la reutilización de código, reduce condiciones innecesarias y permite desarrollar programas más flexibles, organizados y fáciles de mantener.

03

Polimorfismo dinámico

En Python, el comportamiento del método se determina durante la ejecución, dependiendo del objeto que recibe la llamada.

Un ejemplo sencillo

Imagina que tenemos dos animales: un perro y un gato. Ambos pueden realizar la acción de emitir un sonido, pero cada uno produce un resultado diferente.

Esto demuestra cómo una misma operación puede tener diferentes comportamientos según el objeto.

fundamentos.py
class Perro:
    def sonido(self):
        print("Guau")

class Gato:
    def sonido(self):
        print("Miau")

animales = [Perro(), Gato()]

for animal in animales:
    animal.sonido()
Resultado 
Guau
Miau
Recuerda: el polimorfismo permite utilizar una misma operación con objetos diferentes sin necesitar una función distinta para cada uno.
02 / MECANISMOS

Mecanismos de Polimorfismo en Python

Python permite implementar el polimorfismo mediante diferentes mecanismos que hacen posible que los objetos compartan operaciones y tengan comportamientos particulares.

01

Herencia

La herencia permite crear una clase nueva a partir de otra existente. La clase hija puede reutilizar los atributos y métodos de la clase padre, además de agregar funcionalidades propias.

herencia.py
class Animal:
    def comer(self):
        print("El animal está comiendo")

class Perro(Animal):
    def ladrar(self):
        print("Guau guau")

perro = Perro()

perro.comer()
perro.ladrar()
Resultado 
El animal está comiendo
Guau guau

La clase Perro hereda el método comer() de Animal y también tiene su propio método ladrar().

02

Sobrescritura de métodos (Method Overriding)

La sobrescritura ocurre cuando una clase hija redefine un método heredado de su clase padre para proporcionar una implementación diferente.

sobrescritura.py
class Animal:
    def sonido(self):
        print("Sonido general")

class Perro(Animal):
    def sonido(self):
        print("El perro ladra")

class Gato(Animal):
    def sonido(self):
        print("El gato maúlla")

perro = Perro()
gato = Gato()

perro.sonido()
gato.sonido()
Resultado 
El perro ladra
El gato maúlla

Ambos objetos utilizan el método sonido(), pero cada clase proporciona su propia implementación.

03

Despacho dinámico

Es el mecanismo mediante el cual Python determina qué implementación de un método debe ejecutar durante la ejecución del programa, dependiendo del objeto real.

despacho.py
class Auto:
    def mover(self):
        print("El auto avanza")

class Avion:
    def mover(self):
        print("El avión vuela")

def iniciar_transporte(vehiculo):
    vehiculo.mover()

iniciar_transporte(Auto())
iniciar_transporte(Avion())
Resultado 
El auto avanza
El avión vuela

La función iniciar_transporte() no necesita conocer el tipo concreto del objeto. Python ejecuta el método correspondiente al objeto recibido.

04

Duck Typing

Duck Typing es un enfoque de Python en el que importa más lo que un objeto puede hacer que la clase a la que pertenece. Si implementa el método necesario, puede utilizarse.

duck_typing.py
class Impresora:
    def imprimir(self):
        print("Imprimiendo documento")

class Pantalla:
    def imprimir(self):
        print("Mostrando documento")

def ejecutar(dispositivo):
    dispositivo.imprimir()

ejecutar(Impresora())
ejecutar(Pantalla())
Resultado 
Imprimiendo documento
Mostrando documento

Las clases no necesitan heredar de una misma clase. Ambas funcionan porque implementan el método imprimir().

03 / BUENAS PRÁCTICAS

Buenas Prácticas y Control de Tipos

Para aprovechar el polimorfismo es importante escribir código claro, validar los objetos cuando sea necesario y controlar posibles errores durante la ejecución.

Nombres descriptivos

Utiliza nombres claros para las clases y métodos. Por ejemplo: pagar(), imprimir() o enviar_notificacion().

Evitar código repetido

Utiliza una misma función para trabajar con diferentes objetos que implementan el comportamiento requerido.

Validar cuando sea necesario

Puedes utilizar isinstance() para comprobar si un objeto pertenece a una clase o a alguna de sus clases derivadas.

Control de tipos con isinstance()

La función isinstance() permite comprobar si un objeto pertenece a una clase determinada.

Devuelve True si el objeto pertenece a la clase indicada o hereda de ella. De lo contrario, devuelve False.

validacion.py
class Animal:
    pass

class Perro(Animal):
    pass

mi_perro = Perro()

print(isinstance(mi_perro, Perro))
print(isinstance(mi_perro, Animal))
Resultado 
True
True

Identificar el tipo con type()

La función type() permite conocer la clase concreta a la que pertenece un objeto.

Es útil para inspeccionar objetos, aunque para validar compatibilidad con clases base suele ser preferible utilizar isinstance().

tipo.py
class Perro:
    pass

mi_perro = Perro()

print(type(mi_perro).__name__)
Resultado 
Perro

Manejo de errores con try y except

Cuando trabajamos con objetos diferentes, puede ocurrir que alguno no tenga el método que necesita una función.

try y except permiten controlar errores como AttributeError para evitar que el programa termine inesperadamente.

errores.py
class Documento:
    def imprimir(self):
        print("Documento impreso")

def ejecutar(objeto):
    try:
        objeto.imprimir()
    except AttributeError:
        print("El objeto no puede imprimir")

ejecutar(Documento())
ejecutar("Texto")
Resultado 
Documento impreso
El objeto no puede imprimir
04 / APLICACIONES

Casos de Uso Reales

El polimorfismo se utiliza en sistemas de software para trabajar con diferentes objetos mediante operaciones comunes, sin tener que desarrollar una función distinta para cada tipo de objeto.

01

Sistema de pagos

Una aplicación de comercio electrónico puede procesar diferentes métodos de pago mediante una operación común. Cada método realiza el proceso correspondiente.

pagos.py
class Tarjeta:
    def pagar(self):
        print("Pago con tarjeta")

class Transferencia:
    def pagar(self):
        print("Pago por transferencia")

def procesar_pago(metodo):
    metodo.pagar()

procesar_pago(Tarjeta())
procesar_pago(Transferencia())
Resultado 
Pago con tarjeta
Pago por transferencia
02

Sistema de notificaciones

Una aplicación puede enviar notificaciones por diferentes medios, como correo electrónico o mensajes SMS, utilizando el mismo método enviar().

notificaciones.py
class Correo:
    def enviar(self):
        print("Correo enviado")

class SMS:
    def enviar(self):
        print("SMS enviado")

def notificar(servicio):
    servicio.enviar()

notificar(Correo())
notificar(SMS())
Resultado 
Correo enviado
SMS enviado
03

Sistema de vehículos

En un sistema de transporte se pueden manejar diferentes tipos de vehículos utilizando un mismo método para iniciar su funcionamiento.

vehiculos.py
class Automovil:
    def arrancar(self):
        print("Motor encendido")

class Motocicleta:
    def arrancar(self):
        print("Motocicleta encendida")

def iniciar(vehiculo):
    vehiculo.arrancar()

iniciar(Automovil())
iniciar(Motocicleta())
Resultado 
Motor encendido
Motocicleta encendida
05 / ANÁLISIS

Comparativa y Errores Comunes

Comprender las diferencias entre conceptos y reconocer errores frecuentes ayuda a utilizar correctamente el polimorfismo dinámico en Python.

Herencia vs. Polimorfismo

Aunque están relacionados, no significan lo mismo.

La herencia permite que una clase reutilice características de otra. El polimorfismo permite que diferentes objetos respondan de manera distinta ante una misma operación.

comparacion.py
class Animal:
    def sonido(self):
        print("Sonido general")

class Perro(Animal):
    def sonido(self):
        print("Guau")

class Gato(Animal):
    def sonido(self):
        print("Miau")

animales = [Perro(), Gato()]

for animal in animales:
    animal.sonido()
Resultado 
Guau
Miau

Diferencias principales

Concepto Función
Herencia Permite reutilizar atributos y métodos de otra clase.
Sobrescritura Permite redefinir un método heredado.
Despacho dinámico Selecciona qué implementación se ejecuta.
Duck Typing Permite utilizar objetos según las operaciones que implementan.

Errores frecuentes

Estos son algunos errores que pueden aparecer al trabajar con polimorfismo.

Error 1: Confundir herencia con polimorfismo

Tener una clase hija no significa que automáticamente se esté demostrando polimorfismo. Es importante observar cómo se comportan los objetos ante una misma operación.

Error 2: Olvidar sobrescribir el método

Si una clase hija necesita un comportamiento diferente, debe implementar su propia versión del método.

Error 3: Utilizar métodos inexistentes

En Duck Typing, si un objeto no implementa el método esperado, puede producirse un AttributeError.

Error 4: Validar tipos innecesariamente

Comprobar constantemente el tipo de cada objeto puede generar código rígido. Cuando sea posible, aprovecha directamente el comportamiento polimórfico.
